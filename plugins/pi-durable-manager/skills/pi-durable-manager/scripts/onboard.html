Auth-free endpoints receive a non-secret placeholder bearer header. Keys you enter are saved in a private local file and sent only to your endpoint.

This becomes your default model. Add other connections and model profiles anytime in Pi → Settings. DeepSeek-specific compatibility overrides can be set there before running work.

Worker permissions

These are execution permissions, not repository rules. No AGENTS.md is created. Change defaults, project overrides and excluded paths anytime in Settings. Git metadata and manager state remain protected.

Installation downloads dependencies from npm. If Node is missing, the plugin downloads a checksum-verified private Node runtime. Git and a compatible Codex installation are required.
